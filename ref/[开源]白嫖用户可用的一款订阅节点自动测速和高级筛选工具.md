# [开源]白嫖用户可用的一款订阅节点自动测速和高级筛选工具

---

新人第一次发帖，推荐一下自己开源并自用的的订阅管理工具  
项目地址：[GitHub - ZeroDeng01/sublinkPro: ✨ 现代化代理订阅管理平台 | 🏷️智能标签自动分类 ⚡专业测速 🔗链式代理中转 ✈️机场流量监控 🤖TG远程管理 📜JS脚本扩展 | Go+React 全新UI，移动端友好！ · GitHub](https://github.com/ZeroDeng01/sublinkPro)

> [sublinkPro](https://github.com/ZeroDeng01/sublinkPro)是基于优秀的开源项目 `sublinkX`、`sublinkE`进行二次开发，在原项目基础上做了部分定制优化的。

> **适用于各位佬收集公益节点统一管理或者管理自部署的节点。**

> **欢迎各位佬体验并`捉虫子`**

*   在原版的基础上增加了订阅的节点自动导入（支持clash的同时也支持了base64的订阅导入）。
*   修复若干BUG
*   订阅管理的优化，支持按照分组自动选择订阅、手动选择订阅、混合模式选择订阅。
*   支持节点自动测速（延迟和下载速度）和过滤无效节点功能
*   支持js脚本功能
*   支持订阅更新和测试结束通知(右上角个人中心里面设置)
*   ![:fire:](images/image_2__fire_.png ":fire:")前端完全重构，全新的UI交互操作更加便捷，移动端友好
*   ![:fire:](images/image_2__fire_.png ":fire:")落地IP检测
*   ![:fire:](images/image_2__fire_.png ":fire:")节点自动重命名配置

> 各位佬反馈bug和需求可以同步github提交issue，提交issue的话方便问题追踪! ![:saluting_face:](images/image_3__saluting_face_.png ":saluting_face:")

### Docker部署

```bash
docker run --name sublinke -p 8000:8000 \
-v $PWD/db:/app/db \
-v $PWD/template:/app/template \
-v $PWD/logs:/app/logs \
-d zerodeng/sublink-pro
```

### Docker Compose部署

```yaml
services:
  sublinkx:
    image: zerodeng/sublink-pro
    container_name: sublinkx
    ports:
      - "8000:8000"
    volumes:
      - "./db:/app/db"
      - "./template:/app/template"
      - "./logs:/app/logs"
    restart: unless-stopped
```

> 抢先功能体验（开发版）使用docker镜像`zerodeng/sublink-pro:dev`,开发版不建议生产环境使用，仅限功能尝鲜使用

### Linux 一键脚本

```shell
wget https://raw.githubusercontent.com/ZeroDeng01/sublinkPro/refs/heads/main/install.sh   && sh install.sh
```
